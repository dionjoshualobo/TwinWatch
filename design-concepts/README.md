# TwinWatch — splash and icon concepts

Uncommitted review set. Open `preview.html` in a browser and choose one direction.

## Directions

- **A — Red Room**: velvet stripes, forced-perspective checkerboard, double play mark. Palette: `#5A1019`, `#68131E`, `#F4E2C5`, `#FFB454`, `#D9B46E`.
- **B — Forest Signal**: pine-dark greens, CRT scanlines, signal ring around a play core. Palette: `#071B1C`, `#0B2D2B`, `#65E2C1`, `#D7F4EC`, `#FFB454`.
- **C — Diner Ledger`: warm receipt paper, cherry-red ink, TW monogram. Palette: `#EFE7D5`, `#9B3B32`, `#2A1B16`, `#B9AB94`.
- **D — Black Lodge Index`: red corner thresholds, geometric index-eye, black field. Palette: `#070708`, `#BE1C26`, `#F5F0E8`, `#D7C7BB`.

All four are original mood studies only. They avoid protected characters, logos, fonts, quotes, and recognizable artwork.

`PROMPT.md` contains a reusable prompt for generating another independent set with the same constraints.
