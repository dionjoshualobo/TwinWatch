# Cinematic Studio icon concepts

Six new app-icon directions built to match the Cinematic Studio UI revamp: charcoal, warm paper, amber, mint, and coral with film/editorial motifs.

- `01-marquee-play` — filmstrip framing around a clean play disc.
- `02-clapper-play` — clapperboard slash with a play card.
- `03-spotlight` — spotlight beam revealing the play mark.
- `04-reel` — film reel with play negative space.
- `05-split-frame` — two-tone screen split for “together”.
- `06-cue-mark` — editorial corner cues around a play mark.
